### Тема LXP: "КТ №12 Структуры и перечисления"

#### Вариант 2. Слот предмета в игре

1. enum ItemRarity { Common, Rare, Epic, Legendary } — редкость предмета.
2. struct ItemSlot { string ItemName; ItemRarity Rarity; } — с методом, который возвращает бонус к характеристике в зависимости от Rarity (например, Common = +0, Rare = +5, Epic = +15, Legendary = +30).
3. Переопределите ToString(), чтобы вывести название предмета, редкость и бонус.
4. Продемонстрируйте копирование: создайте слот, скопируйте в другую переменную, измените редкость копии и выведите обе — убедитесь, что оригинал не изменился.
5. Продемонстрируйте Enum.TryParse<ItemRarity> на строке, введённой как константа в коде (и на корректном, и на некорректном значении).

Поле перечисления внутри структуры обязательно — задание проверяет именно сочетание struct + enum, а не структуру саму по себе.

| Действие | Ожидаемый результат |
| :--- | :--- |
| `Rarity = ItemRarity.Epic` → бонус | +15 |
| копия слота, изменение `Rarity` копии | оригинал не меняется |
| `Enum.TryParse<ItemRarity>("Rare", out var r)` | `true`, `r == ItemRarity.Rare` |
| `Enum.TryParse<ItemRarity>("Mythic", out var r)` | `false`, без исключения |
