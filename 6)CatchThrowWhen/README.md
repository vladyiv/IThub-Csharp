### Тема LXP: "КТ №6 Множественные исключения. throw, finally, when"

#### Вариант 1. Парсер списка чисел

Метод int SumValidNumbers(List<string> values) суммирует корректные числа из списка строк.
1. Для каждого значения пытайтесь выполнить int.Parse.
2. catch (FormatException ex) when (string.IsNullOrWhiteSpace(value)) — пустые строки пропускайте без логирования (это ожидаемый, частый случай).
3. catch (FormatException ex) (без when) — для остальных ошибок формата выводите предупреждение и продолжайте обработку следующих значений.
4. catch (OverflowException ex) — это считается критической, неожидаемой ситуацией для метода: выведите сообщение и выполните throw;, чтобы передать её вызывающему коду, не теряя стек вызовов.
5. Используйте finally (на каждой итерации или один раз для всего метода — на ваш выбор) для логирования количества обработанных элементов


Для Варианта 1 (Парсер списка чисел), на входе ["10", "", "abc", "20"]:
| Ввод | Вывод |
| :--- | :--- |
| "10" | складывается, сумма += 10 |
| "" | пропускается без предупреждения (фильтр when) |
| "abc" | предупреждение в лог, обработка продолжается |
| "20" | складывается, сумма += 10 |

Итог: сумма 30, метод не выбросил исключение.
