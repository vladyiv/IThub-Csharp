### Тема LXP: "Контрольная точка №18 — лямбда-выражения"
#### Вариант 2. Фабрика обработчиков

1. Func<string, string> через лямбду с телом-выражением — оборачивает строку в кавычки или добавляет префикс.
2. Func<string, bool> через лямбду с телом-блоком из нескольких строк — проверяет строку по нескольким условиям подряд (например, не пустая И длиннее 3 символов) с промежуточными переменными перед return.
3. Лямбда, захватывающая внешнюю переменную (например, префикс), и демонстрация того, что изменение этой переменной после создания лямбды влияет на её поведение.
4. Воспроизведите проблему захвата переменной цикла for: создайте список из трёх лямбд Action, каждая должна была бы печатать «свой» порядковый номер обработчика (0, 1, 2), но из-за захвата общей переменной все печатают одно и то же финальное значение.
5. Исправьте пункт 4, скопировав переменную цикла в локальную переменную внутри тела цикла, и продемонстрируйте, что теперь печатаются разные значения.

Для Варианта 1 (Генератор отчётов):

| Действие | Ожидаемый результат |
| :--- | :--- |
| до исправления: 3 лямбды из цикла `for` | все печатают одно и то же финальное значение (например, 3) |
| после исправления: те же 3 лямбды | печатают `0, 1, 2` — разные значения |

Для Варианта 2 (Фабрика обработчиков): аналогичная структура — до исправления все лямбды из `for`-цикла печатают одно и то же финальное значение, после исправления — разные значения по порядку.
