### КТ №37 LINQ-запросы к коллекциям
#### Вариант 2. Студенты и курсы

1. List<Student> (Id, имя) минимум из 4 элементов.
2. List<Enrollment> (StudentId, название курса, оценка) минимум из 10 элементов, связанных со студентами из пункта 1.
3. Соедините коллекции через Join по Id/StudentId.
4. Сгруппируйте результат соединения по названию курса, посчитайте средний балл и количество студентов на каждом курсе.
5. Отсортируйте курсы по убыванию среднего балла и выведите итоговую сводку.

| Действие | Ожидаемый результат |
| :--- | :--- |
| Join студентов и зачислений | строка результата на каждую пару студент-зачисление |
| группировка по курсу | количество студентов и средний балл соответствуют фактическим данным по курсу |
| сортировка по убыванию среднего балла | курс с наибольшим средним баллом — первый в выводе |
