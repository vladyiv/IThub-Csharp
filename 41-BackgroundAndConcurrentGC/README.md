# КТ №41 Параллельная и фоновая сборка мусора
## Вариант 1. Симуляция нагрузки
1. Метод ShortLived(): 300 000 итераций с new byte[200], ссылки не удерживаются.
2. Метод LongLived(): создать List<byte[]> и добавить в него 5 000 массивов по 512 байт, список оставить жить.
3. Метод HeavyLoh(): создать 20 объектов byte[100_000], удерживать в List.
4. Для каждого метода зафиксировать время выполнения и изменения счётчиков Gen0/Gen1/Gen2 до и после. Вывести таблицу результатов.
5. Явно продемонстрировать разницу: запустить принудительный блокирующий GC.Collect(2, blocking: true) и измерить его паузу отдельно.


| Метод | Ожидаемый результат |
| :--- | :--- |
| `ShortLived()` | много сборок Gen0, мало или 0 Gen2 |
| `LongLived()` | меньше Gen0, явный рост Gen2 со временем |
| `HeavyLoh()` | Gen2 растёт быстрее (LOH — часть Gen2) |
| `GC.Collect(2, blocking:true)` | пауза видна на Stopwatch (> 1–5 мс) |

*Нагенерировала больше данных, что выходные данные совпадали
